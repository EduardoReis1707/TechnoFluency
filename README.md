# TechnoFluency

TechnoFluency is a gamified app concept for learning technical English in technology contexts.

The product helps developers, IT students, and tech professionals learn vocabulary, understand basic technical concepts, and communicate with more confidence in real workplace situations such as bug reports, daily meetings, lead conversations, tickets, documentation, and technical interviews.

## Current Status

This repository currently contains the initial product definition.

- [Product Requirements Document](docs/techno-fluency-prd.md)

## Core Idea

Learn the English that technology professionals actually use at work, starting from basic concepts like bugs, APIs, HTML, and deploys, then progressing into professional communication with leads, teams, recruiters, and stakeholders.
